Upload External Frame for Search

Upload a frame exported from DaVinci Resolve (or any image) to use as a search filter.

Supported formats: JPG, PNG, TIFF (max 50MB)

DaVinci Resolve Integration

To export current frame from DaVinci:

  1. Position playhead on the frame you want to use
  2. Go to DaVinci Console (Workspace > Console)
  3. Run: exec(open('path/to/export_current_frame.py').read())
  4. Frame will be automatically exported and uploaded!

Manual export from DaVinci:

  1. Right-click on timeline at desired frame
  2. Select "Grab Still" > "Export"
  3. Save as JPG and upload here

Once uploaded: The frame's features (colors, objects, visual similarity) can be used as filters in your searches to find similar content.
